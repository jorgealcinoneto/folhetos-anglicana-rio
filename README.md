# Folhetos · Igreja Anglicana Rio

Folhetos litúrgicos dos cultos dominicais da Igreja Anglicana Rio, vinculada à Rede Episcopal Brasileira.

## Acesso

- **Folheto da semana**: <https://jorgealcinoneto.github.io/folhetos-anglicana-rio/>
- **Arquivo por data**: `https://jorgealcinoneto.github.io/folhetos-anglicana-rio/AAAA/MM/DD/`

## Estrutura

```
.
├── index.html           ← último folheto (sempre actualizado)
└── AAAA/MM/DD/index.html ← arquivo permanente de cada domingo
```

## Domingos publicados

- [24/05/2026 — Dia de Pentecostes](https://jorgealcinoneto.github.io/folhetos-anglicana-rio/2026/05/24/)

Liturgia baseada no *Livro de Oração Comum 2015* e na *Portaria Episcopal 01/2025* da Rede Episcopal Brasileira.
